# FedProx Research Results

## Overview

This directory contains the complete experimental results comparing **FedProx** vs **FedAvg** for federated breast cancer histopathology classification across three hospital sites.

## Model Architecture

**EfficientNet-B0 + Fast Coordinate Attention** (5.9M parameters)
- Input: 160×160 RGB histopathology images
- Centralized baseline: 99% test accuracy, AUC 0.9989

## Datasets (19,155 total images)

| Site | Dataset | Source | Images | Benign % |
|---|---|---|---:|---:|
| A | BreaKHis | `ambarish/breakhis` | 7,909 | 31.4% |
| B | Breast Cancer | `djaidwalid/breast-cancer-dataset` | 10,000 | 50.0% |
| C | Histopath. MSI | `zoya77/breast-cancer-msi-multimodal-image-dataset` | 1,246 | 50.0% |
