The aggregation path needs model-aware safeguards.

05

01 · CURRENT BEHAVIOR

Every state-dict tensor is weighted and averaged.

The production FedProx aggregator converts tensors to float, stacks them, and applies sample-count weights to model keys.

02 · TECHNICAL RISK

BatchNorm buffers and counters need explicit treatment.

Integer counters like num_batches_tracked must not be naively averaged; choose and document handling for running stats.

03 · VALIDATION GAP

The simulation does not represent the production vision model.

The experiment uses a small MLP without BatchNorm, so it cannot validate EfficientNet-based aggregation behavior.

Conclusion: add dtype-, key-, and BatchNorm-aware aggregation tests before interpreting FedAvg/FedProx gaps.
