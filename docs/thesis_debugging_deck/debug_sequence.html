Validation protocol

The debugging sequence restores a defensible baseline.

07

The order matters: establish reproducibility and correctness at the smallest scale before interpreting hyperparameters or re-running full three-site FedAvg and FedProx experiments.

01 · REPRODUCIBILITY

Freeze the experiment record.

Set seeds and save dataset indices, configs, checkpoints, and outputs.

02 · AGGREGATION

Test every parameter pathway.

Verify model keys, shapes, dtypes, weights, buffers, and BatchNorm strategy.

03 · EVALUATION

Audit the metric pipeline.

Confirm label mapping, confusion orientation, test split, thresholds, and score extraction.

04 · SANITY CHECKS

Scale only after simple cases work.

Compare centralized, standalone, one-client, and two-client runs from the same init.

Decision gate: resume the μ sweep only when the two-client model has stable, non-degenerate class behavior and the aggregation tests have passed.
